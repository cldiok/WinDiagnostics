# PC Toolkit gerado por IA
Toolkit de diagnóstico e reparo para Windows feito em Rust.

## Features

- Informações do sistema
- Benchmark básico
- Verificação de disco
- Reparo do Windows
- Exportação de relatório

## Compilar

```bash
cargo build --release
```

## Windows Build

```bash
cargo build --release --target x86_64-pc-windows-gnu
```
